# Features

Status of Ocal 0.1.0. The layout borrows ideas from [Fantastical](https://flexibits.com/fantastical). Ocal uses its own interface and Lucide icons.

## Working

| Area | What works |
| --- | --- |
| Views | Day, week, month, agenda and tasks. Narrow windows show three days. |
| Sidebar | Mini calendar, current event, upcoming events, calendar visibility and saved calendar sets |
| Creating events | Keyboard time cursor, Shift ranges, Shift-drag, double-click, context menus and **New event** |
| Event fields | Title, dates, times, calendar, all-day, location, notes, guests, repetition and time zone |
| Meeting links | Paste any link, or generate Google Meet on calendars that support it |
| Editing | Edit, duplicate, and delete with Undo. Google edits check for conflicts. |
| Invitations | Add guests, choose whether Google emails them, and reply Yes, Maybe or No |
| Google accounts | Several accounts, each with its own calendars, cache and sync |
| Search | Titles, locations and notes of cached events |
| Tasks | Local dated tasks with completion, shown in every view |
| Offline | Local calendars, plus read-only cached Google events |
| iCalendar | Import into the local Personal calendar, and basic export |
| Look and feel | Omarchy theme and fonts, light or dark override, zoom |

## Not built yet

| Area | Status |
| --- | --- |
| Moving or resizing events by dragging | Not built |
| Reminders and desktop notifications | Reminder settings are kept. No notifications. |
| Offline Google edits | Not queued. Saving needs a connection. |
| Complex repeat rules | Exceptions and "this and following" edits are not supported |
| Removing a Google account | Not in the app yet |
| Google Tasks | Not built. Tasks are local only. |
| Quarter and year views | Not built |
| CalDAV, iCloud, Exchange and Microsoft accounts | Not built. Google only. |
| Natural-language entry | Not planned |
